# tines-3b-integrations
Each folder contains a plugin/integration that adds Tines 3B functionality to another platform or marketplace.

- [`tines-3b/`](tines-3b/) — Tines 3B [Agent Plugin](https://agent-plugins.org/). Cursor reads [`.cursor-plugin/marketplace.json`](.cursor-plugin/marketplace.json) at this repository root.

Validate from the repository root: `node scripts/validate-template.mjs`
